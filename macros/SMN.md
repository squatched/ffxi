# Book: SMN — Summoner

- **Alt+1** — Hub A / Set 1 (blank on Set 1 itself)
- **Alt+2** — Hub B / Set 2 (blank on Set 2 itself)
- **Alt+0** — Job Hub on both hubs; free on all other sets

**Notes:**
- Each avatar set includes the summon spell plus all Rage/Ward Blood Pacts for that avatar
- Pet commands (Assault, Release, Retreat) live on Hub A since they apply regardless of which avatar is out
- Set 10 reserved as open/flexible — populate with a special avatar, subjob spells, or whatever proves useful in actual play
- Special avatars Cait Sith, Fenrir, Diabolos, and Carbuncle are housed in the [MNK book](MNK.md) (Sets 6-9, built downward from 9). MNK's Set 4 and Set 10 are left empty as bookend buffers. If more overflow is needed, next destination is [THF book](THF.md) (highest set number downward, buffer first).
