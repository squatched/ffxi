# Book: RDM — Red Mage

- **Alt+1** — RDM Hub (blank on Hub itself)
- **Alt+2** — Healing set (blank on Healing itself)
- **Alt+0** — Job Hub on RDM Hub only; free on all other RDM sets
- **Ctrl+0** — Chainspell on RDM Hub, isolated to prevent accidental use

**Excluded spells:**
- Protect I-V, Shell I-V, Reraise — pre-combat set-and-forget
- Bar-element spells — pre-combat; add to overflow if reactive bar-swapping becomes necessary in endgame content
- Bar-status spells — pre-combat; add to overflow if specific content demands it
- Blindna, Paralyna, Poisona — redundant with Erase (Cursna kept as Erase doesn't cover Curse)
- Curaga — RDM does not have native access
- Sleepga — removed; Sleep covers CC needs
